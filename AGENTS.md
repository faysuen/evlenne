# Evlenne page workflow

For every new page or visual page update, first create or update an editable Figma design with desktop and mobile layouts, then implement the page from that Figma design. Reuse the universal header, footer and approved Evlenne logo with its star. Do not publish a page redesign before its Figma template exists.

Current My Pets template: https://www.figma.com/design/LZAP2aAsoRHdpKLhpCQad2

Respond to the user in Chinese, including when their request is in English.
